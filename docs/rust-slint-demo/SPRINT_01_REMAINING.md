## Parallel plan and release gate

- S01 server runtime, S05 Slint components and S06 CI reliability can be developed independently. S02–S04 assemble them at the shared REST and Slint contracts.
- S07 depends on the integrated candidate from S02–S06. A passing fixture-only smoke or compile does not prove the app displayed the JPEG.
- S08 is last: record only checks and captures from the exact candidate SHA. Keep the sprint branch separate from `master` until the designated integration owner accepts the evidence.

The next migration stages cover importing the user’s own photos, SQLite persistence, legacy-catalog migration, the full review/editing workflow and release cutover. Their order is in the [64-task Rust roadmap](../RUST_SLINT_ROADMAP.md#ensamblaje-y-entrega).
