## Parallel work and the final run

- Server integration, shared client/controller, reference capture and CI trigger fixes can start together. Build connections against the API contract with the included fixture and isolated doubles where needed.
- Keep router and package entry-point edits with the D34 integrator. Keep visual work in the Slint layout and component files assigned in the design roadmap. Agree on component properties and callbacks before both sides edit the entry point.
- Run unit and contract checks in feature branches. Run the assembled acceptance matrix against one sprint SHA before proposing promotion to `master`. A cancelled job or a pass against a fixture server leaves the corresponding integrated check pending.

The next migration stages cover importing the user’s own photos, SQLite persistence, legacy-catalog migration, the full review/editing workflow, and release cutover. Their order is in the [64-task roadmap](../RUST_SLINT_ROADMAP.md#ensamblaje-y-entrega).
